Visual Layer provides a flexible filtering system powered by logical structures. You can build filters using the **Filter Menu**, define them in the **Query Modal**, and review or edit them in the **Query Panel**. All applied filters are combined using **AND** logic, allowing you to create precise queries that narrow down your dataset to exactly what you need.

## The Filtering Interface

Visual Layer's filtering interface consists of three main components that work together to help you explore and refine your dataset:

### Filter Menu

The **Filter Menu** is where you select filters to apply. It **dynamically adapts** to your dataset and the context of your view, showing only relevant filter options based on your current logic mode and view context.

<Frame>
  <img src="/images/Drop%20Down_Filters%20Menu.png" alt="Drop Down Filters Menu" />
</Frame>

### Query Modal

Each filter opens a **Query Modal**, where you configure specific filter criteria including conditions, operators, and thresholds. The available options vary by filter type, giving you precise control over how each filter behaves.

### Query Panel

The **Query Panel** shows all active filters, grouped by **AND** logic. This panel provides a clear overview of your current query structure and allows you to edit or remove filters as needed.

## Filter Operators and Conditions

Visual Layer supports multiple operator types to give you flexible control over how filters match your data. The available operators depend on the filter type you're using.

### Comparison Operators

These operators let you include or exclude specific values from your results.

<div className="integrations-table">

| Operator | Description | Available For | Example Use |
|----------|-------------|---------------|-------------|
| **IS** | Matches items that equal the specified value | Labels, Mislabels, Outliers, Quality Issues, User Tags | Show all images labeled as "cat" |
| **IS NOT** | Excludes items that equal the specified value | Labels, Mislabels, Outliers, Quality Issues, User Tags | Show all images except those labeled as "dog" |
| **IS ONE OF** | Matches items that equal any value in a list | Labels, Folders, Files, User Tags | Show images labeled as "cat", "dog", or "bird" |
| **IS NOT ONE OF** | Excludes items that equal any value in a list | Labels | Show all images except those labeled as "cat", "dog", or "bird" |

</div>

**Examples:**

1. **Finding unlabeled data:** Use `Labels → IS → Unlabeled` to surface all images without labels.
2. **Excluding multiple classes:** Use `Labels → IS NOT ONE OF → ["background", "noise", "test"]` to remove unwanted classes from your view.
3. **Isolating quality issues:** Use `Quality Issue → Blurry → IS` with confidence 0.6 to find high-confidence blurry images.

### Pattern Matching Operators

These operators help you find items based on partial text matches in filenames, folder paths, or captions.

<div className="integrations-table">

| Operator | Description | Available For | Example Use |
|----------|-------------|---------------|-------------|
| **CONTAINS** | Matches items containing the specified text | Folders, Files, Captions | Find all files with "train" in the filename |
| **STARTS WITH** | Matches items that begin with the specified text | Folders, Files | Find all folders starting with "batch_" |
| **ENDS WITH** | Matches items that end with the specified text | Folders, Files | Find all files ending with "_processed.jpg" |

</div>

**Examples:**

1. **Finding training data:** Use `Folders → CONTAINS → "train"` to locate all training subsets across different folder structures.
2. **Filtering by file convention:** Use `Files → STARTS WITH → "img_"` to find files following a specific naming pattern.
3. **Isolating processed images:** Use `Files → ENDS WITH → "_final.png"` to find files that have been processed and renamed.

### Text Search Operators (Captions)

Caption search supports advanced logical operators to build complex queries that match textual descriptions.

<div className="integrations-table">

| Operator | Syntax | Description | Example |
|----------|--------|-------------|---------|
| **AND** | `term1 AND term2`<br/>`term1 and term2`<br/>`term1 + term2`<br/>`term1 term2` | Finds results containing both terms | `black AND cat`<br/>`black cat` |
| **OR** | `term1 OR term2`<br/>`term1 or term2` | Finds results containing either term or both | `cat OR dog`<br/>`feline or canine` |
| **NOT** | `-term` | Excludes results containing the term | `dog -black`<br/>`animal -cat -dog` |
| **Exact Match** | `"phrase"` | Matches the exact phrase in quotes | `"yellow flower"`<br/>`"red sports car"` |

</div>

**Examples:**

1. **Simple AND search:** `black cat` finds captions containing both "black" and "cat".
2. **OR for alternatives:** `sunset OR sunrise` finds captions describing either time of day.
3. **Excluding terms:** `car -truck -van` finds captions about cars but not trucks or vans.
4. **Exact phrases:** `"golden retriever"` matches only that specific breed name, not "golden" and "retriever" separately.
5. **Complex combinations:** `(cat OR dog) AND "playing outside" -aggressive` finds playful outdoor pet scenes without aggressive behavior.

<Tip>
Use quotes and parentheses to group logic and ensure complex queries work as expected. For example, `(term1 OR term2) AND term3` ensures the OR is evaluated first.
</Tip>

### Similarity and Threshold Controls

Some filters use sliders or threshold controls instead of dropdown operators.

<div className="integrations-table">

| Control Type | Description | Available For | How It Works |
|--------------|-------------|---------------|--------------|
| **Similarity Level** | Slider from 0 (loose match) to 1 (exact match) | Duplicates | Controls how similar images must be to count as duplicates. Default is 1 (exact or near-exact). |
| **Uniqueness Threshold** | Slider from 0 (redundant) to 1 (unique) | Select Uniques | Filters out images with uniqueness scores below the threshold. Higher values retain only the most distinctive images. |
| **Confidence Threshold** | Slider from 0 (low confidence) to 1 (high confidence) | Quality Issues (Blurry, Dark, Bright) | Sets minimum confidence for quality issue detection. Default is 0.5. Higher thresholds reduce false positives. |

</div>

**Examples:**

1. **Finding near-duplicates:** Set `Duplicates → Similarity 0.9` to catch images that are almost identical but may have minor differences (compression, slight crop).
2. **Creating diverse subsets:** Set `Select Uniques → Threshold 0.7` to retain only images with uniqueness scores above 0.7, removing redundant content.
3. **High-confidence quality issues:** Set `Quality Issue → Blurry → IS → Confidence 0.75` to find only images with very high probability of being blurry.
4. **Sensitive quality detection:** Set `Quality Issue → Dark → IS → Confidence 0.3` to catch more potential dark images, accepting some false positives for thorough review.

## Filter Logic and Behavior

Understanding how Visual Layer combines filters helps you build effective queries.

### Inclusive Filtering (IS)

When you apply an **IS** filter, Visual Layer displays only the items that **match** the specified criteria. This is useful when you want to:

- Review all blurry images in your dataset.
- Examine unlabeled data that needs annotation.
- Identify mislabeled items for correction.
- Surface outliers or edge cases for model testing.

**Example workflow:**

1. Apply `Quality Issue → Blurry → IS` with confidence 0.5.
2. Result: Only images detected as blurry with at least 50% confidence are shown.
3. Review the results, then export for quality improvement or exclusion.

### Exclusive Filtering (IS NOT)

When you apply an **IS NOT** filter, Visual Layer displays only the items that **do not match** the specified criteria. This is useful when you want to:

- Export a clean dataset without blurry, dark, or bright images.
- Remove duplicates before training.
- Exclude specific labels or folders from analysis.

**Example workflow:**

1. Apply `Quality Issue → Dark → IS NOT` with confidence 0.5.
2. Apply `Quality Issue → Blurry → IS NOT` with confidence 0.5.
3. Result: Only images that are neither dark nor blurry are shown (combined with AND logic).
4. Export this clean subset for model training.

### Combining Multiple Filters

All filters in the Query Panel are combined using **AND** logic. This means an item must satisfy **all** active filters to appear in your results.

**Example combinations:**

1. **Clean training subset:**
   - `Labels → IS NOT → Unlabeled`
   - `Quality Issue → Blurry → IS NOT` (confidence 0.6)
   - `Duplicates → Exclude similar items`
   - Result: Only labeled, sharp, unique images

2. **Edge case discovery:**
   - `Outliers → IS` (confidence 0.7)
   - `Labels → IS ONE OF → ["rare_class_1", "rare_class_2"]`
   - Result: Only outliers belonging to specific rare classes

3. **Folder-specific quality review:**
   - `Folders → STARTS WITH → "batch_2024_"`
   - `Quality Issue → Dark → IS` (confidence 0.5)
   - `Mislabels → IS` (confidence 0.6)
   - Result: Dark and mislabeled images from 2024 batches only

## How to Apply Filters

Applying filters in Visual Layer follows a straightforward workflow designed for rapid dataset exploration.

1. Navigate to the **Dataset Exploration View**.
2. Click **Add Filter** in the top filter bar.
3. Select the filter type from the **Filter Menu** (for example, Labels, Quality Issue, Duplicates).
4. Configure your filter criteria in the **Query Modal**:
   - Choose logic operators (IS, IS NOT, CONTAINS, etc.).
   - Set thresholds or similarity levels using sliders.
   - Enter search terms or select values from dropdowns.
5. Click **Apply** to execute the filter.
6. Review active filters in the **Query Panel**, where all filters are combined using **AND** logic.
7. Edit or remove filters as needed directly from the **Query Panel** by clicking on them or using the delete icon.

<Note>
Conditions and input options vary by filter type. For example, Quality Issue filters use confidence thresholds, while Folders and Files support text pattern matching.
</Note>

## Special Filter Workflows

### Applying Uniqueness Filtering

The **Select Uniques** filter uses a different workflow than standard filters:

1. Navigate to the **Dataset Exploration View**.
2. Click the **Select Uniques** button (located next to the search bar).
3. Adjust the **uniqueness threshold slider** to your preferred level.
4. Visual Layer assigns each image or object a **uniqueness score** between `0` (highly redundant) and `1` (highly unique).
5. The filter appears in the **Query Panel** under the **Exclude** section, removing near-duplicates and retaining only the most visually distinct samples.

### Adjusting Confidence Thresholds

For quality issue filters (Blurry, Dark, Bright), you can adjust the **confidence threshold** to control sensitivity:

- **Lower threshold (0.3–0.4):** Catches more potential issues but may include false positives. Use when you want comprehensive quality review.
- **Default threshold (0.5):** Balanced approach with moderate confidence. Recommended for most use cases.
- **Higher threshold (0.6–0.8):** Focuses on high-confidence issues, reducing noise. Use when you want to act only on clear quality problems.

## Tips and Best Practices

**Start broad, then narrow:** Begin with a single filter to understand your dataset's characteristics, then add more filters to refine your view.

**Use exclusion strategically:** IS NOT filters are powerful for creating clean export subsets. Apply multiple IS NOT filters to systematically remove all unwanted content types.

**Leverage text operators for flexibility:** When filtering by Folders or Files, use CONTAINS for flexible matching across different naming conventions.

**Combine thresholds with logic:** Apply quality filters with appropriate confidence thresholds based on your tolerance for false positives vs. completeness.

**Review before export:** Always review the Query Panel to understand which filters are active before exporting data. This ensures you export exactly what you intend.

**Save common queries:** If you frequently use the same filter combinations, document them or create standardized workflows for your team.

**Iterate on confidence levels:** Start with default thresholds (0.5), review results, then adjust up or down based on whether you're seeing too many or too few matches.
