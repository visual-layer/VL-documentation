The **Dataset Inventory** is your home page in Visual Layer, displaying all your datasets in a centralized view. This interface provides quick access to dataset creation, search, filtering, and navigation tools.

### Personal Info Panel

Click your avatar to access account details:

- **Image usage limits**: Current and maximum images based on your plan
- **Subscription status**: Active plan tier and features
- **Light/Dark mode toggle**: Switch between interface themes
- **Logout**: Sign out of your account

<Note>
The default image limit for trial accounts is 10,000 images. Enterprise plans offer custom limits.
</Note>

## Main Panel: Search and Filter

The **Main Panel** at the top of the page provides tools to quickly locate and organize your datasets.

### Search Bar

Use the search bar to find datasets by name. Search is case-insensitive and matches partial names.

**Example:** Searching for "product" will match "Product Images 2024" and "production-test-batch"

### Filter Controls

Apply filters to narrow down the dataset list based on metadata or attributes:

<div className="integrations-table">

| Control | Purpose | Usage |
|---------|---------|-------|
| **Filter by Metadata** | Filter datasets by custom metadata fields | Select metadata values from dropdown menus |
| **Sort By** | Arrange datasets by creation date, status, or name | Choose sorting criteria and order (ascending/descending) |
| **Clear Selection** | Reset all applied filters and return to full dataset view | Click to remove all active filters |

</div>

<Tip>
Combine search and filters for precise dataset discovery. For example, search for "batch" and filter by status "Ready" to find all completed batch datasets.
</Tip>

Each dataset card displays essential information:

<div className="integrations-table">

| Field | Description |
|-------|-------------|
| **Dataset Name** | The title assigned during dataset creation for easy identification |
| **Creation Date** | When the dataset was created and added to your inventory |
| **Dataset Status** | Current state: **Ready**, **Processing**, **Uploading**, **Indexing**, **Failed**, **Resume**, or **Enriching** |

</div>

### Dataset Status Indicators

Understanding status helps you know when datasets are ready for exploration:

<div className="integrations-table">

| Status | Meaning | Available Actions |
|--------|---------|-------------------|
| **Ready** | Dataset is fully indexed and available for all operations | Full access to exploration, filtering, search, enrichment, and export |
| **Draft** | Data upload started but dataset creation was not completed | Click dataset card to resume, then click **Create Dataset** to finalize |
| **Uploading** | Data is being transferred to Visual Layer | Wait for completion; no actions available |
| **Indexing** | Visual Layer is analyzing images, creating embeddings, and detecting quality issues | Wait for completion; indexing may take several minutes to hours depending on dataset size |
| **Processing** | A task is running (enrichment, label propagation, or re-indexing) | Limited actions available; some features disabled until processing completes |
| **Enriching** | AI models are adding metadata (captions, labels, classifications) | Wait for completion; dataset remains accessible for viewing |
| **Pending** | New media was added and requires re-indexing | Initiate re-indexing to make new media searchable and available for analysis |
| **Resume** | Dataset creation started but not finalized; user action required | Click dataset card to resume creation and click **Create Dataset** to complete |
| **Failed** | Dataset creation or processing encountered an error | Click dataset card to view error details; may need to recreate dataset |

</div>

<Note>
Datasets can show **Ready** status even when background tasks like training or enrichment are running, since these operations don't block dataset access.
</Note>

### Card Actions

**Click a dataset card** to open the Dataset Exploration View and begin working with your data.

**Three-dot menu** provides additional actions:
- **Delete**: Permanently remove the dataset (requires confirmation)

<Warning>
Deleting a dataset is irreversible. All images, metadata, annotations, and analysis results will be permanently removed.
</Warning>

## Creating a New Dataset

Click the **Create Dataset** button (+ icon or "New Dataset" button) to start the dataset creation workflow.

The creation workflow guides you through:

1. **Naming your dataset**: Choose a unique, descriptive name
2. **Selecting data source**: Upload ZIP files, folders, or connect to Amazon S3
3. **Previewing your data**: Verify file upload before processing
4. **Adding annotations** (optional): Upload annotation files for labels and bounding boxes
5. **Starting indexing**: Begin the analysis and embedding generation process

You'll receive an email notification when your dataset is ready to explore.

For detailed instructions, see [Upload Data](/docs/quick-start/tutorial-create-dataset).

## Tips for Efficient Dataset Management

**Use descriptive names**: Include dates, sources, or project names to make datasets easy to identify (e.g., "ProductX-Inspection-2024-Q1")

**Monitor status regularly**: Check the Task Manager for long-running operations or errors

**Organize with metadata**: Add custom metadata fields during upload to enable powerful filtering later

**Archive completed projects**: Delete datasets you no longer need to keep your inventory clean and stay within plan limits

**Save important queries as Views**: Once inside a dataset, save filter combinations as Views for quick access to specific subsets
