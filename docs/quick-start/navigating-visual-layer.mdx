Visual Layer organizes its interface around two primary areas. Understanding these areas helps you get started quickly and navigate the platform efficiently.

## Dataset Inventory

The **Dataset Inventory** serves as your home page, displaying all datasets in a centralized view. This area handles dataset creation, organization, and high-level management. You access the **Dataset Inventory** when you first log in and return to it when switching between datasets.

See [About the Dataset Inventory](/docs/quick-start/dataset-inventory-ux) for detailed interface components and features.

## Dataset Exploration View

The **Dataset Exploration View** is your primary workspace for analyzing individual datasets. This interface provides tools for exploring clusters, applying filters, running searches, and managing data quality. You access this view by opening any dataset from the **Dataset Inventory**.

See [About Datasets](/docs/quick-start/dataset-exploration-ux) for detailed interface components and features.

## Navigation Pattern

Visual Layer follows a consistent navigation pattern:

1. **Start** at the **Dataset Inventory** (home page)
2. **Select** a dataset to analyze
3. **Work** in the **Dataset Exploration View**
4. **Return** to the **Dataset Inventory** to switch datasets or create new ones

Both areas include a persistent **Navigation Panel** that provides access to core features like **Task Manager**, **Model Catalog**, and account settings.
