## Navigation Tabs

Three tabs organize your workflow when exploring datasets:

<div className="integrations-table">

| Tab | Purpose | Use Cases |
|-----|---------|-----------|
| **Explore** | Navigate your dataset using clusters, search, and filters | Browse patterns, find similar images, identify quality issues |
| **Data** | View all images in a flat grid without clustering | Review entire dataset linearly, perform bulk selections |

## Filter Panel

The **Filter Panel** provides powerful tools to narrow down your dataset based on specific criteria.

### Add Filter Button

Click **Add Filter** ![](/images/filterbutton.png) to open the filter menu and select from available filter types.

### Available Filters

<div className="integrations-table">

| Filter Category | Purpose | Configuration |
|----------------|---------|---------------|
| **Folders** | Filter by specific folder paths within your dataset | Select folders using checkboxes or path patterns |
| **Files** | Filter by filename or file patterns | Enter filename or use wildcard patterns |
| **Labels** | Filter by assigned label classes or unlabeled status | Select classes to include or exclude using IS/IS NOT operators |
| **User Tags** | Filter by custom tags you've applied | Select tags from your tag list |
| **Captions** | Search by AI-generated or imported captions | Use text search with AND/OR/NOT operators |
| **Mislabels** | Show images flagged as potentially mislabeled | Toggle to show mislabels only or exclude them |
| **Duplicates** | Find duplicate or near-duplicate images | Adjust similarity threshold with slider |
| **Outliers** | Show images that differ significantly from typical patterns | Set confidence threshold for outlier detection |
| **Quality Issues** | Filter by blur, overexposure, underexposure | Select issue types and set confidence thresholds |
| **Select Uniques** | Show only unique images (exclude duplicates) | Adjust uniqueness threshold using slider |

</div>

For comprehensive filter documentation, see [Search and Filter Tool Reference](/docs/explore-and-search/using-search-filter).

### Query Panel

Applied filters appear in the **Query Panel** above the content grid. All filters combine using **AND** logic.

<Frame>
  <img src="/images/applied-filters.png" alt="Applied Filters in Query Panel" />
</Frame>

<div className="integrations-table">

| Control | Function |
|---------|----------|
| **Filter Chip** | Each applied filter shows as a chip displaying its criteria |
| **X Button** | Click to remove an individual filter |
| **Clear All** | Remove all applied filters at once |
| **Edit Filter** | Click filter chip to modify criteria |

</div>

<Note>
Multiple filters combine using **AND** logic. An item must satisfy all active filters to appear in results.
</Note>

## Content Grid: Cluster View

Visual Layer automatically groups visually similar images into **clusters** during dataset indexing. Clusters help you explore patterns and organize large datasets efficiently.

<Frame>
  <img src="/images/clusters-image-view.png" alt="Cluster View" />
</Frame>

### Cluster Cards

Each cluster card displays:

<div className="integrations-table">

| Element | Description |
|---------|-------------|
| **Item Count** | Total number of images matching current filters in this cluster |
| **Prominent Labels** | Most frequent labels within the cluster |
| **Representative Thumbnails** | Key example images that visually summarize the cluster content |
| **Visual Similarity Icon** ![](/images/visual-similarity-icon.png) | Hover over cluster to trigger visual similarity search |

</div>

**Click a cluster card** to drill down and view all images within that cluster.

**Hover and click the similarity icon** to find clusters visually similar to the selected cluster.

### Switching Between Views

Toggle between different visualization modes:

- **Cluster View**: Groups similar images for pattern exploration (default)
- **Image View**: Shows individual images in a grid
- **Object View**: Displays annotated objects grouped by visual similarity (requires object annotations)

## Details Sidebar

The **Details Sidebar** on the right provides dataset statistics, insights, and enrichment options.

### Statistics Panel

View distribution metrics for your dataset:

- **Label distribution**: Breakdown of images by class
- **Quality issue statistics**: Count of blur, dark, bright, and other quality problems
- **Outlier count**: Number of anomalous images detected
- **Duplicate count**: Near-identical images found

Toggle between absolute values (#) and percentages (%) using the switch at the top.

<Frame>
  <img src="/images/issues-toggle.gif" alt="Toggle between counts and percentages" />
</Frame>

### Insights & Issues

Visual Layer automatically detects:

- **Mislabels**: Potentially incorrectly labeled images
- **Duplicates**: Near-identical images that may be redundant
- **Outliers**: Images significantly different from dataset norms
- **Quality Issues**: Technical problems (blur, exposure, compression)

Click any insight to automatically apply a filter and view affected images.

### Enrichment Panel

Access AI models to enhance your dataset:

- **Model Catalog**: Browse available models for classification, captioning, and object detection
- **Run Enrichment**: Apply selected models to generate metadata
- **View Results**: See AI-generated labels, captions, and confidence scores

For details, see [Dataset Enrichment](/docs/advanced-dataset-management/enrich-overview).

## Search Tools

Visual Layer provides multiple search methods to find specific content.

Find visually similar images using deep learning embeddings:

| Search Method | How to Access |
|---------------|---------------|
| **From Cluster** | Hover over a cluster card and click ![](/images/visual-similarity-icon.png) |
| **From Image Details** | Click an image, then click ![](/images/visual-similarity-BUTTON.png) in the action bar |
| **External Image Upload** | Click ![](/images/visual-similarity-searchbaricon.png) near the search bar, upload an image, optionally crop, and start search |

Use natural language queries to find content based on meaning:

**Example queries:**
- "sunset over mountains"
- "people wearing masks"
- "damaged products"

See [How Search & Filter Work](/docs/explore-and-search/explore-theory) for a usage guide.

## Tips for Efficient Exploration

**Start with clustering**: Use Cluster View to quickly understand dataset composition and identify patterns

**Combine multiple filters**: Apply Labels + Quality Issues + Folders filters together for precise subsets

**Save useful queries as Views**: Create Views for common analysis patterns (e.g., "Unlabeled High-Quality", "Mislabeled Products")

**Use visual search for edge cases**: Upload reference images to find rare or specific visual patterns

**Monitor statistics while filtering**: Watch the Details Sidebar to see how filters affect dataset distribution

**Select items incrementally**: Build selection sets across multiple clusters for batch export or tagging

**Check quality insights first**: Review automatically detected issues before starting manual review
