Find answers to common questions about Visual Layer's platform, features, and capabilities.

## General

<AccordionGroup>
  <Accordion title="How can I get started using Visual Layer?">
    Register to Visual Layer [here](https://app.visual-layer.com/login) using your Gmail or GitHub account. Create a dataset and you can begin uploading data.
  </Accordion>

  <Accordion title="What data formats are supported by Visual Layer?">
    Visual Layer allows you to upload images and videos. Supported formats include:

    - **Images**: png, jpg, jpeg, gif, tif, tiff, heic, heif, bmp, webp, jp2, jfif.
    - **Videos**: mp4, avi, dav, m4v, mov, mkv, wmv, flv, webm.

    You can also upload [annotation files](/docs/importing-annotations).

    To request support for other formats, contact us at [support@visual-layer.com](mailto:support@visual-layer.com).
  </Accordion>

  <Accordion title="How much data can I upload to Visual Layer?">
    - **Free Trial**: 10,000 images or 300 minutes of videos per dataset.

    For other plans, contact us at [support@visual-layer.com](mailto:support@visual-layer.com).
  </Accordion>

  <Accordion title="How do I interface with Visual Layer?">
    Visual Layer provides a standards-based REST API and an interactive interface.
  </Accordion>

  <Accordion title="How reliable is Visual Layer Cloud?">
    Visual Layer runs on highly scalable and reliable AWS infrastructure.
  </Accordion>
</AccordionGroup>

## Datasets

<AccordionGroup>
  <Accordion title="What is the difference between Public and Private Datasets?">
    - **Public Datasets**: Explore academic datasets to identify quality issues using Visual Layer. All public datasets are available to every Visual Layer user. Additionally, Visual Layer offers public datasets that have been enriched, showcasing platform capabilities.

    - **Private Datasets**: Datasets you create are visible, accessible, and manageable only to you. Visual Layer is building sharing capabilities to enable team collaboration.
  </Accordion>




</AccordionGroup>



## Deployment Options

<AccordionGroup>
  <Accordion title="Which deployment types are supported by Visual Layer?">
    Visual Layer offers two deployment options:

    - **Visual Layer Cloud**: A hosted service where infrastructure, software, and maintenance are managed by Visual Layer. Access the platform via the internet without installing, updating, or managing any hardware or software. This option is ideal for organizations that prefer a low-maintenance solution and want to start quickly without investing in IT infrastructure.

    - **Self-managed Visual Layer**: Deploy and maintain the Visual Layer platform on your own premises or in a private cloud environment. This approach gives you full control over installation, configuration, and management, allowing customization and integration with existing systems. This option is well-suited for organizations with stringent data security requirements or those that prefer to manage their data infrastructure directly.
  </Accordion>

  <Accordion title="What are the prerequisites for using Visual Layer?">
    To use Visual Layer, you must have a Google or GitHub account.

    The Visual Layer web application runs entirely on the cloud. There is no need to run anything locally or install software.
  </Accordion>

  <Accordion title="What are the prerequisites for using the Visual Layer Self-Managed Solution?">
    Contact [support@visual-layer.com](mailto:support@visual-layer.com) to get more information about this deployment type.
  </Accordion>
</AccordionGroup>

## Search

<AccordionGroup>
  <Accordion title="How does Visual Layer Search work?">
    Visual Layer supports two types of search:

    - **Semantic Search**: Natural language search that leverages Visual Layer models to find specific images based on text queries. The system processes queries to understand context and significance, using natural language processing techniques to handle synonyms, variations, and complex queries.

    - **Visual Search**: Find visually similar content using Visual Layer's engine. Search for similar images, objects, clusters, or upload an external image to find matches. You can also manually select a region of interest to find similar objects. All search capabilities work by relevance or similarity level calculated by Visual Layer.
  </Accordion>
</AccordionGroup>
