This page provides a Python script that converts DICOM (Digital Imaging and Communications in Medicine) files to JPG images while extracting comprehensive metadata. The script prepares medical imaging data for use with Visual Layer by creating converted images and structured metadata that can be uploaded as custom metadata fields.

<Note>
This script is designed for users working with medical imaging data who want to leverage Visual Layer's dataset analysis capabilities. The extracted metadata includes patient information, study details, equipment parameters, and acquisition settings.
</Note>

## What the DICOM Converter Script Does

The DICOM converter script performs comprehensive extraction and conversion of medical imaging data:

**Image Extraction:**
- Converts DICOM files to JPG format for Visual Layer compatibility
- Handles both single-frame and multiframe DICOM files
- Applies proper DICOM processing (windowing, rescaling, photometric interpretation)
- Extracts individual frames from multiframe sequences as separate images

**Metadata Extraction:**
- Extracts comprehensive DICOM metadata from each file
- Captures patient information, study details, and equipment parameters
- Records acquisition settings and image-specific technical details
- Creates structured CSV output linking each image to its metadata

**Organization:**
- Supports both series-organized and flat directory structures
- Creates organized output with separate directories for images and metadata
- Maintains relationships between original DICOM files and converted images

## Complete DICOM-to-Visual Layer Workflow

This section shows the complete end-to-end process for converting DICOM files and creating a fully searchable Visual Layer dataset with comprehensive medical imaging metadata.

### Overview of the Complete Workflow

<Steps>
  <Step title="Extract images and metadata from DICOM files">
    Use the DICOM converter script to convert DICOM files to JPG images and extract comprehensive metadata to CSV format.
  </Step>

  <Step title="Create Visual Layer dataset">
    Upload the converted JPG images to Visual Layer to create a new dataset for analysis and exploration.
  </Step>

  <Step title="Export dataset for media_id mapping">
    Export your Visual Layer dataset to obtain the critical mapping between filenames and Visual Layer's internal media_id values.
  </Step>

  <Step title="Upload DICOM metadata as custom fields">
    Use the specialized DICOM metadata upload script to automatically process and upload the extracted metadata as searchable custom fields.
  </Step>

  <Step title="Analyze medical imaging data">
    Use Visual Layer's advanced search, filtering, and analysis capabilities with your comprehensive DICOM metadata.
  </Step>
</Steps>

### Step 1: Convert DICOM Files

First, convert your DICOM files to extract images and metadata:

```bash
# Basic conversion
python dicom_converter.py /path/to/dicom/files

# With verbose output to see detailed progress
python dicom_converter.py /path/to/dicom/files --verbose

# Custom output directory
python dicom_converter.py /path/to/dicom/files --output /custom/output/path
```

**What this creates:**
- `converted_images/` directory with JPG files ready for Visual Layer
- `metadata/dicom_metadata.csv` with comprehensive metadata for each image
- Organized naming that maintains relationships between images and source DICOM files

### Step 2: Create Visual Layer Dataset

Upload the converted JPG images from the `converted_images/` directory to create a new Visual Layer dataset using either:
- Visual Layer web interface (drag and drop the images)
- Visual Layer API for programmatic dataset creation

### Step 3: Export Dataset Metadata

Once your dataset is created in Visual Layer, export it to get the `metadata.json` file that contains the critical mapping between your image filenames and Visual Layer's internal `media_id` values. This mapping is essential for the next step.

### Step 4: Upload DICOM Metadata

Use the specialized DICOM metadata upload script to process and upload your extracted metadata:

**For Cloud installations:**
```bash
python upload_csv_with_json_mapping.py dicom_metadata.csv metadata.json \
  --dataset-id=your-dataset-id \
  --base-url=https://app.visual-layer.com \
  --api-key=your-api-key \
  --api-secret=your-api-secret
```

**For On-premises installations:**
```bash
python upload_csv_with_json_mapping.py dicom_metadata.csv metadata.json \
  --dataset-id=your-dataset-id \
  --base-url=http://localhost:2080 \
  --api-key=your-api-key
```

### Step 5: Analyze Medical Imaging Data

Once your DICOM metadata is uploaded, you can perform advanced medical imaging analysis in Visual Layer:

**Clinical Research Applications:**
- Filter patients by age, sex, and study parameters
- Compare acquisition settings across different equipment manufacturers
- Analyze image quality metrics across different scanning protocols
- Group studies by date ranges and clinical indications

**Quality Assurance Workflows:**
- Identify outliers in exposure parameters (kVp, tube current)
- Monitor consistency of slice thickness and spacing across studies
- Track equipment performance and software versions
- Analyze windowing settings for optimal image display

**Dataset Curation:**
- Search for specific modalities and study types
- Filter by patient demographics for research cohorts
- Identify multiframe vs. single-frame acquisitions
- Organize by series descriptions and acquisition dates

### Command Line Parameters

| Parameter | Required | Description | Default |
|-----------|----------|-------------|---------|
| `input_dir` | ✅ | Directory containing DICOM files or series subdirectories | - |
| `--output` | ⭕ | Output directory path | `input_dir/output_YYYYMMDD_HHMMSS` |
| `--format` | ⭕ | Output image format (jpg, png, bmp, tiff) | `jpg` |
| `--verbose` | ⭕ | Enable detailed logging output | `false` |
| `--series` | ⭕ | Process only specific series (e.g., series-00001) | All series |

### Input Directory Structure

The script supports two DICOM organization patterns:

**Series-Organized Structure (Recommended):**
```
input_directory/
├── series-00001/
│   ├── image001.dcm
│   ├── image002.dcm
│   └── image003.dcm
├── series-00002/
│   ├── image001.dcm
│   └── image002.dcm
└── series-00003/
    └── multiframe.dcm
```

**Flat Directory Structure:**
```
input_directory/
├── scan001.dcm
├── scan002.dcm
├── scan003.dcm
└── multiframe.dcm
```

<Tip>
The script automatically detects multiframe DICOM files and extracts each frame as a separate JPG image with individual metadata entries.
</Tip>

### Output Structure

The script creates an organized output directory:

```
output_directory/
├── converted_images/

│   ├── series-00001_image002.jpg
│   ├── series-00002_image001.jpg
│   ├── series-00003_multiframe_frame-001.jpg
│   ├── series-00003_multiframe_frame-002.jpg
│   └── series-00003_multiframe_frame-003.jpg
└── metadata/
    └── dicom_metadata.csv
```

### Metadata CSV Structure

The generated CSV file contains comprehensive metadata for each converted image:

**File Information:**
- `image_filename` - Generated JPG filename
- `original_dicom_path` - Original DICOM file path
- `series_folder` - Series directory name
- `conversion_timestamp` - Processing timestamp
- `is_multiframe` - Boolean indicating multiframe source
- `frame_number` - Frame number (1 for single-frame)
- `total_frames` - Total frames in source DICOM

**Patient Information:**
- `patient_id`, `patient_name`, `patient_birth_date`
- `patient_sex`, `patient_age`

**Study Information:**
- `study_instance_uid`, `study_date`, `study_time`
- `study_description`, `accession_number`

**Equipment Information:**
- `manufacturer`, `manufacturer_model_name`
- `device_serial_number`, `software_versions`, `modality`

**Acquisition Parameters:**
- `slice_thickness`, `slice_location`
- `kvp`, `tube_current`, `exposure_time`
- `window_center`, `window_width`
- `pixel_spacing`, `rows`, `columns`

## Troubleshooting

### Common Issues

**No DICOM files found:**
- Verify your input directory contains `.dcm` files
- Check that files are valid DICOM format
- Ensure proper directory permissions

**Conversion failures:**
- Some DICOM files may have unsupported formats or corrupted data
- Check the verbose output for specific error messages
- Verify DICOM files can be opened with standard DICOM viewers

**Missing metadata fields:**
- Not all DICOM files contain every possible metadata field
- Empty or missing values are handled gracefully
- Customize the script to extract additional vendor-specific tags if needed

**Memory issues with large datasets:**
- Process large datasets in smaller batches
- Ensure sufficient disk space for output files
- Consider processing series directories individually

**Upload timeouts or failures:**
- Large datasets may take time to process
- The upload script waits indefinitely - you can interrupt with Ctrl+C if needed
- Check Visual Layer logs for any processing errors
- Use the `--resume` flag to continue from where you left off

### Script Customization

The DICOM scripts are designed to be adaptable for different medical imaging workflows:

- **Field detection logic** can be modified to handle specific DICOM tag requirements
- **Custom preprocessing** can be added for vendor-specific implementations
- **Additional metadata fields** can be incorporated based on your imaging protocols
- **Processing workflows** can be extended for specialized DICOM formats

For complex customization requirements, Visual Layer can provide guidance on adapting the scripts to your specific use case.
