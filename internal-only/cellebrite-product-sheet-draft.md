# Visual Layer: Turn Visual Evidence into Actionable Intelligence

Images and videos contain critical visual evidence, but manual review doesn't scale. Visual Layer enables investigators to search visual data by meaning, surfacing patterns, identifying people, and exposing connections across millions of files in seconds. ***This is visual intelligence that finds what manual review misses.***

## Visual Layer Features: See Everything. Find Anything.

### SEARCH & DISCOVER

Visual Layer automatically organizes visual evidence into meaningful clusters, providing immediate insight into what exists before investigators begin analyzing. Built-in models handle visual complexity and edge cases without custom training.

| Capability | Description |
| :---- | :---- |
| **Visual Clustering** | Automatically groups visually similar visual evidence, revealing evidentiary patterns at a glance |
| **Semantic Search** | Natural language queries uncover content by concept: "passport," "weapon," "vehicle," "aggressive activity" |
| **Visual Search** | Search using images or objects as queries. Upload a reference, select from findings, or target specific items—including partial or hidden objects like passports in hands or weapons in backgrounds |
| **Hybrid Search** | Combine concepts, faces, and visual structure in a single query; save searches as monitored views |

### PEOPLE INTELLIGENCE

Visual Layer automatically detects and groups faces, transforming raw visual evidence into structured, searchable subject entities. All detected people are centralized in a dedicated People View where investigators can review face clusters, resolve identities, and name individuals.

| Capability | Description |
| :---- | :---- |
| **People View** | Centralized view of all detected faces, with tools to review clusters, resolve identities, and name individuals |
| **People Appearance Timeline** | Full timeline of appearances, activity trend chart, and media gallery: understand both presence and behavior |
| **Relationship Graph** | Graphical representation showing all subjects who appear together, ranked by frequency; relationship graph exposes groups and network structures |
| **Behavioral Context** | Shows which investigative views each subject appears in (weapons, violence, documents) |
| **Location Display** | Capture locations displayed as metadata, connecting subjects, activity, and geography |

### INVESTIGATIVE VIEWS

Predefined and custom views provide immediate investigative guidance and can be monitored for new matches.

| Capability | Description |
| :---- | :---- |
| **Predefined Views** | Auto-generated views based on detected concepts (weapons, vehicles, documents, aggressive activity); fully customizable and provide initial insights |
| **Custom Views** | Save any search or filter combination as a reusable view to match investigation priorities |
| **Monitored Views** | Receive alerts when new visual evidence matches saved view criteria |

### VL CHAT

Natural language interface for conversational visual evidence exploration.

| Capability | Description |
| :---- | :---- |
| **Conversational Search** | Query case data using natural language with multi-turn context |
| **Query Interpretation** | Transparent JSON output shows how queries are parsed and executed |
| **Smart Suggestions** | Contextual suggestions guide effective query formulation |

### COLLABORATION, NOTEBOOK & CASE INTEGRATION

The Notebook serves as an investigation workspace for structured thinking and reporting.

| Capability | Description |
| :---- | :---- |
| **Collaboration** | Shared views, export data, share notebook etc.  |
| **Evidence Collection** | Collect people, images, maps, and relationship graphs in one place |
| **Narrative Building** | Write insights, assumptions, and open questions to build a clear investigative narrative |
| **Flexible Formats** | Structure as a summary, person dossier, or full investigation report |
| **Case Attachment** | Attach directly to Cellebrite cases, preserving all visual evidence, context, relationships, and insights |

## Technical Specifications

Processes petabyte-scale visual evidence collections efficiently with CPU-first infrastructure, enabling cost-effective deployment at any volume.

### Supported Evidence Formats

| Type | Formats |
| :---- | :---- |
| **Images** | PNG, JPG, JPEG, GIF, TIF, TIFF, HEIC, HEIF, BMP, WebP, JP2, JFIF |
| **Videos** | MP4, AVI, DAV, M4V, MOV, MKV, WMV, FLV, WebM |

### API Capabilities

| Category | Description |
| :---- | :---- |
| **Evidence Ingestion** | Bulk upload, streaming ingestion, metadata attachment, folder-based organization |
| **Semantic Search** | Natural language queries across visual evidence with confidence scoring |
| **Visual Search** | Image-based similarity search with configurable thresholds |
| **Multi-Query** | Combined semantic \+ visual \+ metadata filter queries in single request |

### Deployment Options

| Option | Description |

| Integration Point | Description |
