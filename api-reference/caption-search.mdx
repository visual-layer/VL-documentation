Caption search is available through the **Semantic Search** endpoint using the `caption` parameter.

<Card title="Go to Semantic Search" icon="scan-text" href="/api-reference/semantic-search">
  Full documentation for caption search, VQL text filters, and semantic vector search is on the Semantic Search page.
</Card>

## Quick Reference

Search by caption using the `GET /api/v1/explore/{dataset_id}` endpoint with the `caption` query parameter:

```bash
curl -H "Authorization: Bearer <jwt>" \
  "https://app.visual-layer.com/api/v1/explore/<dataset_id>?caption=cars+on+highway&entity_type=IMAGES&threshold=0&textual_similarity_threshold=0.5"
```

For full parameter reference, response structure, VQL text filters, and Python examples, see [Semantic Search](/api-reference/semantic-search).

<Note>
The `image_caption` parameter is deprecated. Use `caption` instead.
</Note>
